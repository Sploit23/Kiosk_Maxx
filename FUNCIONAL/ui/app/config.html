ℹ️ Como Organizar as Fotos:

  • Selecione a pasta principal onde estão suas fotos
  • Escolha o formato de pasta de data que você prefere usar:
  • DDMMYYYY: Exemplo: 15112025
  • DDMMYY: Exemplo: 151125
  • YYYYMMDD: Exemplo: 20251115
  • YYMMDD: Exemplo: 251115
  • Dentro da pasta principal, crie subpastas seguindo o formato escolhido
  • O sistema automaticamente procurará pela pasta do dia atual no formato selecionado
  • Importante: Após fazer alterações, clique em "Salvar" para aplicar as mudanças
